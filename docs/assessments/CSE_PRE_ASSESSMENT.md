# CSE Pre-Assessment

**Branch:** Computer Science and Engineering (CSE)
**Total:** 80 MCQs (4 sections of 20) + 2 coding questions
**Level:** Medium
**Suggested time:** 120 minutes

| Section | Questions | Type | Suggested time |
|---|---|---|---|
| 1. Quantitative Aptitude | 20 | MCQ (2–4 options) | 25 min |
| 2. Logical Reasoning | 20 | MCQ (2–4 options) | 20 min |
| 3. Verbal Ability | 20 | MCQ (2–4 options) | 15 min |
| 4. Technical (CSE) | 20 | MCQ (2–4 options) | 30 min |
| 5. Coding | 2 | Programming | 30 min |

**Instructions for candidates**
- Each MCQ has exactly one correct answer. Marks are +1 for a correct answer and 0 for an unanswered one.
- Coding questions are scored on correctness across hidden test cases, then on time and space complexity.
- Use of a calculator is not allowed in Sections 1 and 2.
- The answer key is at the end of this document. Remove it before the assessment is shown to candidates.

### Coding Question 2: Merge Overlapping Intervals

You are given a list of intervals `[start, end]`. Merge all intervals that overlap, and return the merged list sorted by start. Two intervals that only touch at an endpoint (for example `[1, 4]` and `[4, 5]`) count as overlapping.

**Function:** `merge_intervals(intervals: list[list[int]]) -> list[list[int]]`

**Constraints**
- 0 ≤ number of intervals ≤ 100000
- 0 ≤ start ≤ end ≤ 10⁹
- The input may be unsorted.

**Examples**

| Input | Output |
|---|---|
| `[[1,3],[2,6],[8,10],[15,18]]` | `[[1,6],[8,10],[15,18]]` |
| `[[1,4],[4,5]]` | `[[1,5]]` |
| `[[5,7]]` | `[[5,7]]` |
| `[]` | `[]` |

**Expected complexity:** O(n log n) time, O(n) space.

### Section 5: Coding (reference solutions)

**Q1: Longest substring without repeating characters**

```python
def length_of_longest_substring(s: str) -> int:
    last_seen = {}   # character -> index of its most recent occurrence
    start = 0        # left edge of the current window
    best = 0
    for i, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= start:
            start = last_seen[ch] + 1
        last_seen[ch] = i
        best = max(best, i - start + 1)
    return best
```

**Q2: Merge overlapping intervals**

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    merged = []
    for start, end in sorted(intervals, key=lambda iv: iv[0]):
        if merged and start <= merged[-1][1]:   # overlaps or touches
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged
```
